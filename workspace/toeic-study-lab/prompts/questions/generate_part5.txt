【条件】
・英文中に1つの空所（_____）を設けること
・選択肢は4つ（A/B/C/D）
・文法・語法の知識を問う問題にすること
・正解は1つに確定すること
・ひっかけの選択肢を含めること
・正解の選択肢の位置（A〜D）はどこでもよい（後工程でランダムに並び替えるため、位置を気にする必要はない）

【カテゴリ一覧（grammar_category と grammar_point の有効な値）】

  [Level 1: 頻出]
  parts_of_speech （品詞）: noun / verb / adjective / adverb
  verb_form （動詞の形）: tense / subject_verb_agreement / modal
  active_passive （能動／受動）: passive_voice
  infinitive （不定詞）: to_infinitive
  gerund （動名詞）: gerund
  participle （分詞）: present_participle / past_participle
  preposition （前置詞）: preposition
  conjunction （接続詞）: conjunction
  pronoun （代名詞）: pronoun

  [Level 2: 中級]
  comparison （比較）: comparative / superlative / as_as
  relative_clause （関係詞節）: relative_pronoun
  noun_clause （名詞節）: noun_clause
  subjunctive （仮定法）: subjunctive
  inversion （倒置）: inversion

  [Level 3: 高得点帯]
  vocabulary （語彙）: vocabulary
  collocation （コロケーション）: collocation
  idiom （イディオム）: idiom
  phrasal_verb （句動詞）: phrasal_verb
  context （文脈）: context

【各項目の説明】
・question_text: 空所(_____)を含む英文
・choice_a〜choice_d: 選択肢となる英単語または英語表現
・correct_answer: 正解の選択肢を示す "A" 〜 "D" のいずれか1文字
・explanation: 日本語での解説（問われている文法ポイントと、正解が成立する理由を説明する）
・difficulty: "basic" / "standard" / "hard" のいずれか
・grammar_category: 上記カテゴリ一覧のカテゴリキー（例: "participle"）
・grammar_point: 上記カテゴリ一覧のサブカテゴリキー（例: "past_participle"）
・question_translation: question_text全体の自然な日本語訳（_____部分も訳に含めること）
・choice_translations: choice_a〜choice_dそれぞれの日本語訳。キーは"A"〜"D"
・choice_explanations: 各選択肢ごとに「なぜ正解／不正解なのか」を初学者向けに簡潔に説明する。キーは"A"〜"D"
  - 正解の選択肢 → なぜ文法的に正しいかを説明する
  - 誤答の選択肢 → なぜ文法的に誤り・不自然なのかを説明する

【explanation・choice_explanationsに関する重要な制約】
・explanationおよびchoice_explanationsの本文中では、選択肢を「A」「B」「C」「D」のアルファベットで指してはならない
・選択肢を指す場合は、その選択肢の英語表現そのもの（例："discussing"）を使って説明すること
（理由：後工程で選択肢の並び順を変更するため、アルファベットへの言及があると説明と矛盾が生じる）

【整合性チェック】
・question_text / choice_a〜choice_d / correct_answer / explanation / choice_explanations の内容に矛盾がないこと
・correct_answerは必ずchoice_a〜choice_dのいずれかに対応していること
・grammar_category と grammar_point は必ず上記カテゴリ一覧の値を使うこと
・choice_translations / choice_explanationsのキー（A〜D）はchoice_a〜choice_dと1対1で対応していること

【出力形式に関する重要な制約】
・必ずJSON形式のみを出力すること
・Markdownのコードブロック（```などの記号）を使わないこと
・JSON以外の説明文、前置き、後書きを一切出力しないこと
